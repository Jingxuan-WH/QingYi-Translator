# 轻译 0.5.0

- **翻译时可以停下来。** 译文生成期间，翻译按钮变成「停止翻译」。再次开始时会使用当前原文。误清空原文后，可以直接撤销。
- **长译文更容易阅读。** 译文分批追加到输出区。在 Mac 上，向上翻看前文时，新译文会留在下方，滚回底部即可继续跟随。
- **小窗口也能对照原文和译文。** 缩窄主窗口后，两栏改为上下排列，放宽后恢复左右排列。切换布局时保留正在编辑的文字。
- **常用操作就地完成。** 首次打开会直接进入翻译窗口，需要配置服务时可点「添加 API Key」。取消首次选择文件会返回原来的窗口。在术语表中误删了一行，可以在保存之前点「撤销删除」恢复。
- **状态变化更清楚。** 打开历史、切换文件翻译阶段和显示操作反馈时使用短过渡。主要过渡会跟随系统的动态效果偏好。

**下载**　macOS 13 及以上请选 `QingYiTranslator-mac.zip`（Apple 芯片和 Intel 通用），Windows 10/11 请选 `Translator.exe`。已安装轻译也可以在设置中检查更新。

## English

Stop an active translation from the main window, undo an accidental clear, or recover deleted glossary rows before saving. Narrow windows stack the source and translation vertically. Long translations appear in batches, and on Mac you can scroll back to read without incoming text pulling you to the end. Short transitions explain changes in history and file translation and respect system motion preferences.

Download `QingYiTranslator-mac.zip` for macOS 13 or later, or `Translator.exe` for Windows 10/11.
