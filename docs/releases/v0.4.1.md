# 轻译 0.4.1：修复 Mac 翻译期间输入丢字

## 修复

- **macOS：修复翻译过程中继续输入，新文字可能在译文刷新或翻译完成时被清除的问题。** 现在可以边翻译边继续输入，无需等待上一句翻译完成。
- 保护输入框中尚未同步的文字和中文输入法尚未确认的候选内容，避免界面刷新时被旧原文覆盖。
- 清空原文、载入历史记录等主动替换原文的操作保持正常。

Windows 版同步版本号至 0.4.1，没有功能改动。

## 下载与升级

- **macOS 13 及以上**：下载 `QingYiTranslator-mac.zip`，支持 Apple 芯片和 Intel。解压后退出轻译，用新的 `QingYi Translator.app` 替换旧版。
- **Windows 10 / 11**：下载 `Translator.exe`，需要 .NET 10 桌面运行时。
- 已安装版本也可通过设置中的「检查更新」升级；设置、API Key、术语表和翻译历史会保留。

## 验证

- 新增 5 项 Mac 输入框回归测试，覆盖翻译刷新期间继续输入、未同步的输入、中文组合输入、清空原文和载入历史文本。
- Mac 本地全部 125 项测试通过，修复版已在本机安装并经实际使用确认。

---

**QingYi 0.4.1 fixes lost input on macOS while a translation is running.** New text, including uncommitted Chinese input, could previously be overwritten when the translation pane refreshed or the request finished. You can now keep typing without waiting for the previous translation to finish.

Five regression tests cover input preservation and explicit source replacement. All 125 Mac tests pass locally, and the installed fix has been verified in normal use. Windows receives a version bump only, with no functional changes.

Download `QingYiTranslator-mac.zip` for macOS 13+ (Apple silicon and Intel), or `Translator.exe` for Windows. You can also update from Settings → Check for updates. Your settings, API keys, glossary and translation history are preserved.
